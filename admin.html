Kết nối tới kho GitHub

Nhập thông tin repo và token để trang này đọc/ghi trực tiếp vào file index.html trên GitHub Pages của bạn.

⚠️ Token là chìa khoá vào repo của bạn. Trang này lưu token trong trình duyệt máy bạn (không gửi đi đâu khác ngoài GitHub) — chỉ dùng trên máy cá nhân, không dùng ở máy công cộng. Xem hướng dẫn tạo token an toàn ở khung "Xem mã / tải file".
Tạo tại GitHub → Settings → Developer settings → Fine-grained tokens. Cấp quyền Contents: Read and write chỉ cho repo này.

Dự phòng

Xem mã / tải file

Nếu không muốn dùng token, sửa nội dung ở các tab rồi tải file index.html đã cập nhật về, upload thủ công lên GitHub.

1. Vào github.com → ảnh đại diện → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
2. Ở "Repository access", chọn Only select repositories → chọn đúng repo tramdungthoigian.
3. Ở "Permissions" → Repository permissions → tìm Contents → chọn Read and write.
4. Bấm Generate, copy token (chỉ hiện một lần) và dán vào ô Token ở tab "Kết nối kho".
